# Database-Recovery-Using-EBS
Based on EC2 Instance, Volume, Snapshot and AMI.

Project Overview:
This project demonstrates how Amazon Elastic Block Store (EBS) snapshots can be used to back up and recover data associated with an Amazon EC2 instance.

AWS Services Used:
Amazon EC2
Amazon EBS
EBS Snapshots

Project Workflow:  
Identify the EBS volume attached to the EC2 instance.
Create an EBS snapshot to back up the volume.
Use the snapshot to create a new EBS volume.
Attach the restored volume to an EC2 instance.
Verify data recovery by checking the restored files.

Objective:
To understand EBS backup and recovery concepts and practice data recovery procedures on AWS.
